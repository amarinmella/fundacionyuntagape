# Fundación Yuntagape — Sitio Web

Sitio web oficial de la **Fundación Yuntagape**, una organización dedicada al acompañamiento terapéutico y educativo de niños y familias.

## 📄 Páginas

| Archivo | Descripción |
|---------|-------------|
| `inicio.html` | Página principal con hero, misión y llamados a la acción |
| `servicios.html` | Detalles de los servicios terapéuticos y educativos |
| `quienes.html` | Información sobre el equipo y la fundación |
| `contacto.html` | Formulario de contacto e información de ubicación |

## 🛠 Tecnologías

- HTML5
- CSS3 (estilos embebidos)
- JavaScript (vanilla)
- Diseño responsivo (mobile-first)

## 🚀 Uso

Simplemente abre `inicio.html` en un navegador web, o despliega los archivos en cualquier servidor de hosting estático (GitHub Pages, Netlify, Vercel, etc.).

### Despliegue con GitHub Pages

1. Sube este repositorio a GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
4. GitHub publicará el sitio en `https://<tu-usuario>.github.io/<nombre-repo>/inicio.html`.
